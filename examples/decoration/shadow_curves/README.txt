Authoritative fitted-shadow preview (800x480 RGB565)

Run: bazel run //examples/decoration/shadow_curves:shadow_curves

One rectangle animates from index 0 to 31 and back, first with a 10-second
sine cycle, then a 10-second triangle cycle, repeating indefinitely. Small
static rectangles show 0.5 and 1 dp. Both key and ambient are enabled.

The example uses the library renderer directly. Authoritative parameters are
src/roo_windows/decoration/shadow_parameters.h, generated by
benchmarks/generate_shadow_parameters.py from the frozen selected coefficients
in benchmarks/shadow_parameters_fit.json. Logical recipes are also exported to
benchmarks/shadow_parameters.csv. Key uses the free-offset and free-blur fits;
ambient uses power laws. Reference heights are 0, 3, 5, 8, 10, 14 dp. Half-dp
indices still mean 0..15.5 dp, with all lengths rounded after zoom to 1/16 pixel.
Zero explicitly disables shadows. Side/corner caches remain off by default.

Regenerate parameters: python3 benchmarks/generate_shadow_parameters.py
Regenerate optional gradients: python3 benchmarks/generate_shadow_gradients.py
Historical fit plots remain in shifted_anchor_results for reference; they do
not select or override the renderer's parameters.
